# Workspace Markdown Editor

واجهة تطوير محلية لبناء وتحرير ملفات Markdown داخل مساحة العمل، مع خادم Express بسيط وواجهة React أنيقة. الهدف هو تقديم محرر سريع يمكن الوصول إليه من الشبكة المحلية (أو من نفس الجهاز) مع واجهات برمجة تطبيقات صغيرة لإدارة الملفات النصية.

## نظرة عامة

- **الخادم**: `Express.js` يقدم واجهات REST لقراءة/كتابة ملفات `.md` من جذر مساحة العمل.
- **الواجهة**: تطبيق React (بدون أدوات بناء) يستخدم Babel في المتصفح، بتصميم احترافي مناسب للشاشات الكبيرة والصغيرة.
- **الاتصال**: الخادم يستمع على `0.0.0.0`، ما يسمح بالوصول عبر عنوان الشبكة المحلية (مثلاً `http://192.168.1.189:3000`).
- **الأمان**: التحقق من المسارات يضمن عدم الخروج عن مجلد مساحة العمل، ولا توجد ملفات يتم تقديمها خارج `public/`.

## المزايا

- استعراض جميع ملفات Markdown ضمن workspace (مع دعم المجلدات المتداخلة).
- تحميل الملف المختار وتحريره مباشرة في المتصفح مع حفظ فوري عبر API.
- واجهة حديثة بعمود جانبي للقائمة ومحرر نصي بخط أحادي سهل القراءة.
- دعم اللغة العربية بالكامل في المحتوى والواجهة (يمكن تعديل النصوص بسهولة).

## تشغيل المشروع

```bash
npm install    # للتأكد من تثبيت التبعيات (تم مسبقاً، كررها فقط عند إضافة حزم)
npm start      # يشغل الخادم على المنفذ 3000 افتراضياً
```

- يمكن تغيير المنفذ أو المضيف عبر المتغيرين `PORT` و `HOST`.
- لوقف الخادم: إنهاء العملية أو استخدام أداة إدارة الجلسة في بيئة OpenClaw.

## هيكل الملفات

```
workspace/
├─ server.js          # خادم Express وواجهات API
├─ public/
│  └─ index.html      # واجهة React + Babel
├─ AGENTS.md          # تعليمات تشغيل البيئة
├─ SOUL.md            # شخصية المساعد
├─ USER.md            # تفضيلات المستخدم
├─ IDENTITY.md        # هوية المساعد
├─ memory/            # سجلات يومية
└─ ...
```

## واجهات API

| الطريقة | المسار        | الوصف                                           |
|---------|---------------|--------------------------------------------------|
| GET     | `/api/files`  | إرجاع قائمة شجرية بكل ملفات Markdown في الجذر |
| GET     | `/api/file`   | قراءة ملف واحد (`?path=relative/path.md`)      |
| POST    | `/api/file`   | حفظ ملف (`{ path, content }`) بعد التحقق      |

> جميع المسارات تستخدم `JSON` وتتحقق من أن الملف داخل مساحة العمل.

## ملاحظات إضافية

- عند تشغيل الخادم في بيئة حقيقية، يُفضل إضافة طبقة مصادقة (JWT، Basic Auth، أو VPN) لحماية ملفاتك.
- لدمج React كامل مع حزمة بناء (Vite/Next)، يمكن نقل الواجهة إلى مشروع منفصل وإعداد Proxy أو استخدام نفس Express لتقديم ملفات الإنتاج.
- لأي تحسينات مستقبلية (معاينة Markdown، نسخ احتياطية، سجل تعديلات)، ابدأ بكتابة مخطط في `memory/YYYY-MM-DD.md`.
